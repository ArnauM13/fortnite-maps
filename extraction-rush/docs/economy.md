# EXTRACTION RUSH — Economia i Progressió

L'economia és el que converteix partides soltes en una **base de jugadors activa**: dona motiu per tornar (no perdre l'estança, completar missions, pujar de nivell).

## Moneda: Valor (💠)

Cada objecte té un valor. En extreure amb èxit, el valor s'afegeix a la teva **estança persistent**. En morir, perds tot el valor que portaves a sobre en aquella ronda (però NO el que ja tens guardat a l'estança).

| Objecte | Valor 💠 | On es troba |
|---------|---------|-------------|
| Ferralla / component | 5 | Zona 1 |
| Objecte de valor mitjà (rellotge, joia) | 25 | Zona 2 |
| Artefacte èpic | 100 | Zona 3 |
| Clau daurada (multiplicador x2) | especial | Zona 3 |
| Artefacte llegendari (event setmanal) | 500 | Zona 3 (només event) |

## Bucle d'inversió (risk-reward loop)

```
Extreus valor 💠 ──► Estança (persistent)
        │
        ├──► Compres millor LOADOUT de deploy (entres més fort)
        ├──► Compres KEYCARDS per accedir directe a La Bòveda
        └──► Desbloqueges ranures d'inventari extra (portes més botí)
```

Com millor és el loadout, més profund pots arriscar-te → més valor potencial → però també més a perdre. Aquest és el motor de decisions.

## Nivells de loadout de deploy

| Nivell | Cost 💠 | Contingut |
|--------|---------|-----------|
| Recluta (per defecte) | 0 | Pistola comuna + 1 cura |
| Operatiu | 300 | Rifle poc comú + escuts |
| Veterà | 1.000 | Rifle èpic + cures + granades |
| Fantasma | 3.000 | Loadout complet + keycard Bòveda |

## Missions diàries (XP → nivells de temporada)

Es reinicien cada 24 h. Donen XP independentment de si extreus o mors — així el jugador sempre progressa i no es frustra.

| Missió | XP | Exemple |
|--------|----|---------| 
| Extreu amb èxit 1 cop | 200 | Completa una ronda viu |
| Recull 3 objectes de valor | 150 | Loot a qualsevol zona |
| Entra a La Bòveda | 250 | Arriba a la Zona 3 |
| Elimina 2 jugadors | 200 | PvP |
| Extreu amb 500+ 💠 en una ronda | 400 | Ronda d'alt risc |

## Nivells de temporada

- Cada nivell de temporada desbloqueja un **cosmètic** (skin, emote, wrap) o **valor** de bonificació.
- Barra de progrés visible al lobby → sensació de progrés constant.
- **Passe gratuït** perquè la retenció no depengui de pagar.

## Balanç anti-frustració (clau per no perdre jugadors)

- **Assegurança de loadout**: pots "assegurar" 1 arma per ronda amb valor; si mors, la recuperes. Redueix la sensació de pèrdua total.
- **Estança segura**: el valor guardat MAI es perd. Només arrisques el de la ronda actual.
- **Extracció ràpida garantida a Zona 1**: sempre hi ha una sortida "segura" amb poc botí per als jugadors cautelosos.
- **XP encara que moris**: les missions no requereixen sempre extreure.

## Mètriques de retenció a vigilar

| Mètrica | Objectiu | Per què importa |
|---------|----------|-----------------|
| Ronda mitjana | 5–8 min | Sessions curtes = "una més" |
| Taxa d'extracció | 35–50% | Massa alta = avorrit; massa baixa = frustrant |
| D1 retention | >30% | Salut de la base |
| Missions completades/dia | >2 | Enganxament diari |
